# Swanky Pro — версия для просмотра

## Как скачать и открыть

1. Откройте `Swanky-Pro-download.zip` в этой папке на GitHub.
2. Нажмите кнопку скачивания **Download raw file** (значок стрелки вниз).
3. Распакуйте ZIP на компьютере.
4. Откройте `Swanky-Pro.html` двойным щелчком в Chrome, Edge, Safari или Firefox.

Можно скачать и отдельный `Swanky-Pro.html` той же кнопкой. На телефоне сохраняйте файл и открывайте в браузере: встроенные просмотрщики документов могут не выполнять JavaScript.

Шрифты Bounded и Disruptor’s Script встроены. Установка шрифтов, пакетов и запуск сервера не нужны. Интернет требуется для переходов на внешние сайты.

Это дизайн-прототип без реальной оплаты и отправки заказов. Корзина хранится в текущем браузере; правила хранения локальных файлов зависят от браузера. Moodnail не редактировался.

`Swanky-Pro-preview.png` — снимок первого экрана обновлённого Swanky Pro.

Автономная загрузка, встроенные шрифты, смешанная корзина и ширины 390/768/1440 проверены без сети через перехват главной HTML-загрузки. Прямое открытие file:// в проверочном браузере среды запрещено административной политикой, поэтому двойной щелчок на пользовательском устройстве отдельно не подтверждён.

Эта ветка содержит файлы для скачивания и не публикует сайт.
