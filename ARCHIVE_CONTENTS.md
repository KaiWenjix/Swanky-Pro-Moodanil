# Состав архива и сохранность исходников

Дата: 27.10.2026. Исходный коммит: `cba0d41ae1119f904ece16193a39b8df58bfa697`.

## Основная папка

- `project/` — все 271 текущих отслеживаемых файла исходного проекта, побайтно скопированные из рабочего дерева. Ничего не перерисовано и не переписано для передачи. Дополнительно скопированы две реально существовавшие декларации типов, а не приблизительные замены.
- `history/project-history.bundle` — полная доступная история Git, 11 коммитов; не содержит конфигурацию авторизации прежнего аккаунта. Инструкции восстановления — в PROJECT_HANDOFF.md.
- `PROJECT_HANDOFF.md` — актуальная русская инструкция для следующего ИИ. Отдельная копия этого же документа передаётся рядом с ZIP.
- `VERIFICATION.md` — результаты проверки сохранности, сборки и тестов.
- `SOURCE_MANIFEST.json` — имя, размер и SHA-256 каждого скопированного исходника/материала.
- `SHA256SUMS.txt` — контрольные суммы всех файлов архива, кроме самого списка сумм.
- `reference/Swanky-Pro-Concept.html` — ранее созданный просмотр, без повторной генерации при упаковке. Это только эталон, разработка ведётся по project/.
- `materials/` — доступные исходные материалы разработки и исследования. Они не импортируются приложением как дополнительные страницы и не заменяют public/.

## Что не включено и почему

- `node_modules/` — установленные пакеты для Linux, около 974 МБ. Они восстанавливаются через pnpm 11.25.0 по package.json и pnpm-lock.yaml. Архив не является офлайн-установщиком всех npm-пакетов.
- Рабочая `.git/` — вместо неё включён полный переносимый Git bundle. Не переносятся Git credential helpers, remote-авторизация и права аккаунта.
- Build outputs `dist/`, `.vinext/`, содержимое `.next/` кроме сохранённого routes.d.ts, `tsbuildinfo`-кэши вне отслеживаемых файлов — воспроизводимые артефакты. Отслеживаемый оригинальный tsconfig.tsbuildinfo оставлен без изменений как часть снимка; его можно пересоздать проверкой TypeScript.
- `.sites-runtime/`, `.wrangler/`, локальные кэши, служебные логи и вспомогательные файлы загрузки в Library — относятся к прежней среде, а не к приложению.
- Один незавершённый временный загрузочный файл в папке исследования не включён; это не используемый ресурс приложения. Все файлы public/ сохранены.
- Локальные env-файлы в корне проекта не обнаружены. Их приблизительные копии или секреты не создавались.
- Браузерные данные пользователя (корзина, профиль, избранное, тестовые заказы) не являются файлами исходного проекта и недоступны в этой среде; автоматически не переносятся.

## Отсутствующие исходники

Отсутствующих файлов из текущего Git-списка **нет**. Реальные доступные изображения, шрифты, видео и исходные материалы сохранены. Figma, RAW, PSD и проекты видеоредактора, которых не было в доступной среде, не выдумывались. Полный старый диалог и доступы к аккаунту архивом не экспортируются.

## Важное различие

`project/docs/` включает исторические документы. Их прежние палитры Swanky, число товаров, видео-решения и описания некоторых интеграций могут отличаться от последней версии. Следовать PROJECT_HANDOFF.md и текущему коду; не возвращать старую концепцию автоматически.
